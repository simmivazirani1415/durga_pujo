# PujoBLR

An auto-rickshaw ride through Durga Puja in Bengaluru: drive from stop to stop, halt at each neighbourhood's pandal, explore its 2026 pandals, food and events, and collect a Pujo medallion at every stop.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm install
npm run build
```

The build is a single self-contained file, `dist/index.html` (fonts, images and code inlined). Host it as a static page; it needs no server and makes no network requests of its own.
